# Four Card Feature Section

Minha solução para o desafio [Four Card Feature Section](https://www.frontendmentor.io) do Frontend Mentor.

## Sobre o projeto

Uma seção responsiva com quatro cards. No celular, os cards aparecem em uma coluna. Em telas maiores, usam três colunas: Supervisor à esquerda, Team Builder e Karma no centro, e Calculator à direita.

## Tecnologias

- HTML
- CSS
- CSS Grid

## O que pratiquei

- Estrutura HTML com `main`, títulos e rodapé
- Layout responsivo com CSS Grid
- Pesos diferentes da fonte Poppins
- Alinhamento dos ícones dentro dos cards
- Espaçamento e largura com `rem`, `%` e `max-width`

## Como executar

Abra o arquivo `index.html` no navegador.
